Want it to move your real cursor?

Right now the button runs a fullscreen demo: it hides your cursor and flies a drawn pointer around. That's the most a web page is allowed to do — browsers block pages from touching the OS pointer, so that a site can't park your cursor over “Allow” and click it for you.

To move the actual cursor, set it up once. After that this page moves your real mouse every time you open it, forever, with nothing to run.

Download install.cmd

Double-click it. It installs the agent to your user folder, starts it now, and starts it again at every login. Takes about five seconds. uninstall.cmd removes everything — no registry keys, no services, no admin rights.

Paste this into Terminal once. A downloaded .command file arrives without execute permission and quarantined, so this is the path that actually works:

curl -fsSL https://pvsp2003.github.io/random-mouse-mover/scripts/install_macos.command | bash

It installs a LaunchAgent that starts the agent at every login. macOS will then ask for Accessibility permission — you must grant it, or the cursor won't move. Undo with launchctl unload ~/Library/LaunchAgents/com.randommousemover.agent.plist.
