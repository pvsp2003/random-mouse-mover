Random Mouse Mover

One button. Your real cursor goes somewhere else.

 

Browsers can't move the system cursor from a web page — so run this one-file agent and the button above takes over your real mouse.

  1. 1
    Download mouse_mover.ps1
  2. 2
    Run it in a terminal, from wherever you saved it:
    …
  3. 3
    Come back and press the button. Ctrl+C in the terminal stops it.

The agent listens on 127.0.0.1 only, so nothing outside your machine can reach it. On Safari, use http://127.0.0.1:8777/ instead of this page — Safari blocks HTTPS pages from talking to localhost. macOS will ask for Accessibility permission on the first hop; grant it to the app you launched the agent from.
