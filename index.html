Other platform / details
  • mouse_mover.ps1 — Windows. PowerShell only, nothing to install.
  • mouse_mover.py — macOS, Linux and Windows. Uses CoreGraphics / X11 / Win32 through ctypes, so no pip install on macOS or Windows.
  • Flags: --interval 5 (seconds between hops), --jump 0.5 (max hop as a fraction of the screen), --once.
  • macOS asks for Accessibility permission the first time — grant it to Terminal in System Settings → Privacy & Security → Accessibility.
